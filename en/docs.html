A step-by-step guide to BlendParser.

Reviewed for alpha-0.0.2. Screenshots show the actual workflow; some controls may change between versions.

Your first conversion

BlendParser converts a Blender model with materials or textures into a 3MF painted by filament. Open that file in Bambu Studio to choose settings and prepare the print.

  1. Install Blender 3.6 or later and download BlendParser for Windows or Linux.
  2. Open the app and drag in a .blend file or click Choose file.
  3. Select your printer in the top bar and check the final height.
  4. Choose your colors, compare Original and Result and touch up as needed.
  5. Click Export .3mf, save the file and open the result in Bambu Studio.

The app needs Blender installed to read the file. You do not need to compile the project to use the installers.

Installation and updates

Windows

In the downloads section, choose the .exe or .msiinstaller. The app uses WebView2, normally included in Windows 11. Current installers are not signed for Windows distribution; SmartScreen may show a warning. Check that the file comes from the official repository.

Linux

Options include AppImage, Debian (.deb) and RPM. For an AppImage, enable execution permission before opening it. Choose the package for your distribution and keep Blender installed.

Check for new versions

Version 0.0.2 checks for updates shortly after opening. You can also click the version number in the top bar. When an update is available, it offers to download and install it; export any work you want to keep first, because the app restarts. Offline, you can keep using the installed version.

Prepare your Blender file

Save a normal .blend. Files such as .blend1, .blend2 are backups: open them in Blender and save them as .blend before importing.

Extraction reads the scene’s visible meshes and evaluates their modifiers. Color can come from an image with UV coordinates, vertex color attributes or a flat material color.

  • Check that the meshes you want to convert are visible.
  • If you use images, make sure Blender can find them and that the model has UVs.
  • Check the scene units, then confirm the height in millimeters inside BlendParser.

The result is not a Blender render: lighting, reflections and complex node combinations may look different. The extractor looks for material color sources; it does not reproduce all shading. For an image without UVs, it may use an average color.

Size, printer and plate

Final height is in millimeters. Changing it scales the width and depth proportionally. The selected printer determines which plate is used to check whether the model fits.

If you see Does not fit on plate, use Fit to plate. This reduces the scale to leave room in width and depth. If you export without fitting it, the app asks for confirmation. This plate check does not replace checking the full print volume in Bambu Studio.

Flatten the base

Enter the amount to trim and click Flatten or press Enter. The field accepts 0 to 50 mm; 0 disables trimming. Start with a small amount and check the preview and contact area. Trimming changes the geometry of the base.

Colors and AMS slots

Detect a palette

Under Detect again with you can choose 2, 3, 4, 5, 6, 8, 10 or 12 colors. The palette is calculated from the model. Adjust each target color to the filaments you have: the app does not automatically read the spools in your printer.

Edit a slot

The circle opens the color picker. The card selects that slot for painting and activates the brush. It also shows its hex color, triangle count and closest matching slot.

Merge colors

Merge closest down to reduces the palette to the specified number, preserving hand-painted work and allowing undo. You can also use Merge into… to choose the destination for a specific slot.

Before detecting again: recalculating the palette or clicking Suggest colors again discards manual painting. If you have already painted, the app asks for confirmation. To reduce colors while keeping your painting, use color merging.

Choosing more colors in the app does not add physical slots to your equipment. Review your filament configuration in Bambu Studio.

Viewer and 3D brush

Original shows the source color; Result shows the filament colors. Switch between them to judge how much reducing the palette changes the appearance.

Select a slot, activate Brush and drag over the mesh. The radius ranges from 0.5 to 20 mm in 0.5 mm steps. The active color appears below the viewer. Undo a stroke with the Undo button or its keyboard shortcut.

Reduce filament changes

The change and purge estimate helps compare settings; it is not an exact figure for your print. The 0.0.2 calculation uses 0.2 mm layers, 280 mm³ of purge per change and PLA density. Bambu Studio may give different results depending on its settings.

  1. Try merging colors that are barely distinguishable.
  2. Under Clean islands smaller than, carefully increase the minimum area: small patches take on their neighbors’ color. Set it to 0 to disable it.
  3. Review Edge detail: the level ranges from 0 to 5. More detail preserves color boundaries better; less detail simplifies them.
  4. Compare the Result view and the estimated changes before exporting.

Islands are measured by area in mm². Do not confuse them with loose parts in the Mesh group, which are controlled by size in millimeters.

Repair and simplify the mesh

Repair mesh merges duplicate vertices and removes degenerate triangles and repeated faces. The summary shows what was fixed or whether the mesh was already clean.

Remove loose parts smaller than removes small components based on their size. Leave it at 0 to keep them, and check that increasing it does not remove a detail you want.

Simplify controls the percentage of geometry to keep: 100% keeps the mesh, and lowering it reduces the triangle count. Check the silhouette and color boundaries; too much simplification can remove details you want to print.

Automatic repair does not guarantee that every model becomes printable. Also review the result and warnings in Bambu Studio.

Export the result

Multicolor 3MF

Click Export .3mf, choose where to save it and open the file in Bambu Studio. Colors are assigned by filament. Check the spools, printer profile, orientation and slicing settings before sending the print.

By color (.zip), in alpha-0.0.2

This output creates a closed STL per color and a color reference inside a ZIP. It is intended for working with separate parts.

  • Thickness of each color: from 0.2 to 20 mm; the default is 1.2 mm.
  • Main color as a full solid: keeps the main color as a complete solid instead of treating it as a shell.

About the assembly kit: the new options for per-color plates, part depth and an illustrated guide are not included in the alpha-0.0.2 release documented here.

Troubleshoot common issues

Blender cannot be found

Install Blender or use Find blender.exe when the app offers it. The app also supports the BLENDER_PATHenvironment variable. Reload the model after setting the path.

The file has no visible meshes

Open the file in Blender, check that visible mesh objects exist and save your changes. The extractor does not convert cameras or lights into parts.

Colors do not match

Check materials, images and UVs in Blender. Compare Original with Result: a palette difference can be corrected by adjusting slots; a texture that was not read needs checking in the source file.

The model is too large

Select the correct printer and use Fit to plate. If you only change the printer profile, check the size warning again.

Purge differs from Bambu Studio

This is an estimate for comparing settings. The slicer calculates the print with its own color sequence and purge parameters.

I cannot update

Check your connection and click the version to check again. You can also download an installer from the official releases. Export your work before installing or restarting.
